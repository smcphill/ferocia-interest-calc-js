# Term Deposit Calculator

A simple calculator for term deposits, modelled on (and testable via) https://www.bendigobank.com.au/calculators/deposit-and-savings/


## Setup

Make sure you have Node.js installed.

Install dependencies:
```
npm install
```

## Running

Run the calculator with:
```
node calculator.js
```

## Testing

Run tests with:
```
npm test
```
